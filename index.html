Sobre o NutriControl

Conheça a proposta do projeto acadêmico.

O que é o NutriControl?

O NutriControl é uma plataforma demonstrativa desenvolvida para representar processos administrativos relacionados ao controle de notas fiscais, estoque e movimentações de produtos no setor de nutrição hospitalar.

Objetivo

Demonstrar como ferramentas de desenvolvimento web podem auxiliar na organização de informações e no acompanhamento de processos administrativos.

Tecnologias utilizadas

HTML5 CSS3 JavaScript LocalStorage GitHub Pages
Importante: Este projeto é exclusivamente acadêmico e demonstrativo. Todos os registros são fictícios. Não utilizei dados de pacientes, documentos fiscais reais ou informações internas de instituições.
